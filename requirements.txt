# =============================================================================
# Eco-Travel Advisor — pinned dependencies
# =============================================================================
# Every version below was cross-checked directly against PyPI's metadata
# (not guessed) to make sure this single shared environment actually
# resolves — this is the one part of a Rasa + FastAPI project that silently
# breaks most often, so it's worth being explicit about *why* each pin is
# what it is:
#
#   * rasa==3.6.21 is the exact version this project's worksheets were
#     written against. It requires Python >=3.8,<3.11 (hence the
#     python:3.10-slim base image in the Dockerfile — 3.11/3.12 will NOT
#     install rasa 3.x at all) and pydantic<1.10.10.
#   * fastapi + uvicorn are pinned to the last pydantic-1-generation
#     releases so the flight_data_service can live in the SAME environment
#     as Rasa without a pydantic v1/v2 clash. Its own Pydantic usage (one
#     plain BaseModel) doesn't need anything from v2.
#   * pydantic==1.10.9 is the newest 1.10.x release that still satisfies
#     rasa's "<1.10.10" ceiling, and has proper cp310 wheels.
#
# If you change any of these, re-check both constraints again — this
# combination was the whole point of pinning it this precisely.
